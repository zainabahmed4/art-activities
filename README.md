# Web Development Project 1 - *Chicago Artsy Activities*

Submitted by: **Zainab Ahmed**

This web app showcases a curated list of artsy activities in Chicago, perfect for any creative or art appreciator visting the city. Places include museums, cultural centers, art studios, and interactive creative experiences. Each card includes a short description, image, and link to learn more.

## Notes

Some challenges I encountered while building this app were learning how to structure a React/Vite project, understanding the difference between `main.jsx` and `App.jsx`, and fixing JSX syntax issues such as using `className` instead of `class`. I also had to adjust the card layout so the content, images, and buttons fit cleanly without being cut off or overlapping.

Another challenge was making the card grid responsive. I learned how to use CSS Grid, `gap`, fixed card sizing, and media queries so the site can show multiple cards on desktop while still working well on smaller screens. I also practiced importing Google Fonts, setting a background image, and organizing styles between `index.css` for global styling and `App.css` for component-specific styling.
